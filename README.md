# COPD急性加重多模态表型发现（开源代码）

> 对应论文：《真实世界多模态电子病历驱动的慢阻肺急性加重表型发现》（投《中国数字医学》）

## 研究概述
从真实世界六源电子病历（检验、医嘱、微生物、影像、肺功能、病历文本）数据，**无需结局标签**，用无监督聚类（K均值）发现慢阻肺急性加重住院患者的3种可解释多模态表型：
- **P1 低炎症型**（嗜酸细胞偏高、病情轻）
- **P2 中间型**
- **P3 高炎症高碳酸型**（中性粒/CRP/PCO₂/NT-proBNP升高，重症）

表型经肺功能GOLD分级外部锚定、特征归因、bootstrap稳定性、多算法对比、多重敏感性分析验证，与真实世界治疗强度（有创插管、广谱抗菌、通气支持）呈梯度匹配。

## 运行方法
按顺序执行（每步输出供下一步使用）：
```bash
python 01_特征工程.py        # 输出: s1_feature_matrix.csv
python 02_插补标准化_聚类.py   # 输出: 表型标签 + s1_phenotyped.csv
python 03_表型验证.py         # 输出: 验证指标（锚定/归因/稳定性/多算法）
python 04_关联分析.py         # 输出: 表型×结局/用药关联表
```

## 关键方法学决策（与论文一致）
1. **聚类输入仅用9项生物学指标**（血常规分类、CRP、D-二聚体、PCO₂、氧合指数、NT-proBNP），**不含**住院日/费用（避免用结局定义表型）
2. **偏态指标log转换**（白细胞/CRP/D-二聚体/NT-proBNP）后KNN插补+Z-score标准化
3. **剔除极端值**（白细胞>50或<1，排除白血病样异常）
4. **K=3依据**：K=2轮廓系数更高但仅分2簇、临床区分度不足；K=3簇规模均衡+临床可解释性最强（低/中/高三梯度）
5. **表型验证仅用未参与聚类的独立变量**（住院日/费用/病原学/治疗模式），避免循环论证
